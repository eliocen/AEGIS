# AEGIS Data Directory

This directory contains the dataset structure used by the AEGIS research framework.

## Directories

- `raw/` — original source datasets
- `interim/` — partially processed data
- `processed/` — model-ready datasets
- `benchmark/` — benchmark and evaluation datasets
- `external/` — externally sourced auxiliary datasets

Large datasets are intentionally excluded from Git.

Dataset provenance, licensing, language distribution, class taxonomy, preprocessing procedures, and train/validation/test splits will be documented as datasets are integrated into AEGIS.

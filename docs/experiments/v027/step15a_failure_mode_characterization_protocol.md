## 5. Step15B — H9-F failure decomposition

### Question

Where do the heterogeneous M4qcf-minus-M1b robustness gains and losses
underlying H9-F occur?

For every eligible seed-condition observation:

`R_i = MacroF1(M4qcf, i) - MacroF1(M1b, i)`

The analysis must retain all 54 observations.

Required stratification:

- seed;
- corrupted modality;
- corruption family;
- severity;
- modality × corruption family;
- corruption family × severity;
- modality × severity.

Required outputs include all 54 R_i values, positive/non-positive counts,
grouped means, grouped positive proportions, severity trajectories, and
the largest positive and negative observations.

The frozen H9-F decision remains **NOT_SUPPORTED** regardless of favorable
subgroups.

## 6. Step15C — H8-to-H9 mechanism characterization

### Question

How is corrupted-modality down-weighting associated with downstream
classification change?

For each of the same 54 observations:

`D_m = mean(weight_corrupted_modality_clean) - mean(weight_corrupted_modality_corrupt)`

and

`R_i = MacroF1(M4qcf, i) - MacroF1(M1b, i)`

Required analyses:

- paired D_m/R_i table;
- descriptive Pearson correlation;
- descriptive Spearman rank correlation;
- modality-stratified association;
- corruption-family-stratified association;
- severity-stratified association;
- quadrant characterization.

The four diagnostic quadrants are:

1. D_m > 0 and R_i > 0;
2. D_m > 0 and R_i <= 0;
3. D_m <= 0 and R_i > 0;
4. D_m <= 0 and R_i <= 0.

These analyses are descriptive. Correlation does not establish that
fusion-weight changes caused classification changes.

## 7. Step15D — H10-F mismatch pathway decomposition

### Question

Why does compatibility-informed interaction suppression occur under
mismatch without reducing mismatch-induced classification degradation
relative to M1b?

For M1b, M4qc, and M4qcf, characterize matched and mismatched:

- Macro-F1;
- accuracy;
- matched-to-mismatched degradation.

For M4qcf additionally characterize:

- compatibility score;
- interaction multiplier;
- text and vision fusion weights;
- effective text and vision reliability;
- matched-to-mismatched changes.

At sample level characterize:

- correct → correct;
- correct → incorrect;
- incorrect → correct;
- incorrect → incorrect;
- prediction-flip rate;
- confidence changes by transition group.

M4qc remains descriptive causal-control evidence only.

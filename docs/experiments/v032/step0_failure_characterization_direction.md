# AEGIS v0.32 Step0 鈥?Utility-Learning Failure Characterization Direction

v0.32 is an analysis-only mechanism-characterization cycle following the immutable
v0.31.0 release. v0.31 preserved clean performance but failed all five formal
hypotheses. Its utility probabilities remained near 0.5 and active intervention
remained zero across the principal validation strata.

The purpose of v0.32 is therefore to diagnose why the utility-learning pathway
failed before any successor intervention architecture is designed.

The characterization examines the frozen counterfactual candidate utility signal,
the delta_u and u_target distributions, candidate-action benefit frequency,
utility-selector learning, and evidence-to-utility discrimination.

No v0.31 model is retrained or modified. No new formal evaluation is run. The
official test split remains sealed.
